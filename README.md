# 🎟 লটারি টেলিগ্রাম মিনি অ্যাপ (৳ BDT, ম্যানুয়াল পেমেন্ট)

কোনো `npm install` লাগে না — শুধু **Node.js 22.13+** দরকার।

## ফিচার
**ইউজার:** লটারি তালিকা ও কাউন্টডাউন • র‍্যান্ডম বা নিজের পছন্দের নাম্বারে টিকিট কেনা • আমার টিকিট • ফলাফল • ডিপোজিট (bKash/Nagad/Rocket, TrxID দিয়ে) • উত্তোলন (ফি সহ) • লেনদেনের ইতিহাস • রেফারেল বোনাস • বটে নোটিফিকেশন

**এডমিন প্যানেল (`/admin/`):** 💳 পেমেন্ট মেথডের ছবি/লোগো আপলোড • ড্যাশবোর্ড (আয়/দায়/মুনাফা) • ডিপোজিট অনুমোদন/বাতিল (পরিমাণ বদলানো যায়) • উত্তোলন অনুমোদন/বাতিল (বাতিলে অটো রিফান্ড) • লটারি তৈরি/এডিট/বাতিল • **ম্যানুয়াল ড্র** (চাইলে নিজে বিজয়ী টিকিট ঠিক করা যায়, না দিলে র‍্যান্ডম) বা অটো ড্র • ইউজার সার্চ, ব্যালেন্স যোগ/কর্তন, ব্লক/আনব্লক, ইউজারকে মেসেজ • সব ইউজারকে ব্রডকাস্ট • পেমেন্ট নাম্বার, ফি, লিমিট, বোনাস, ঘোষণা, মেইনটেন্যান্স মোড সেটিংস • সব লেনদেনের লগ

## জিপে কী কী আছে
`.env` (আগে থেকে তৈরি, এডমিন পাসওয়ার্ড অটো-জেনারেট করা) • `.env.example` • `system-requirements.txt` • `README.md` • `package.json` • সোর্স কোড • `public/` (ইউজার অ্যাপ, এডমিন প্যানেল, ৩ডি ইফেক্ট)

## সেটআপ
0. জিপ এক্সট্রাক্ট করে `.env` খুলে `BOT_TOKEN`, `WEBAPP_URL`, `BOT_USERNAME` বসান।
1. @BotFather → `/newbot` → টোকেন নিন। তারপর `/newapp` (বা Bot Settings → Configure Mini App) এ আপনার HTTPS URL দিন।
2. `cp .env.example .env` করে `BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_PASSWORD`, `BOT_USERNAME` বসান।
3. `node --no-warnings server.js` (বা `npm start`)
4. HTTPS দরকার — VPS হলে Nginx/Caddy + Let's Encrypt, অথবা টেস্টের জন্য `cloudflared tunnel --url http://localhost:3000`।
5. এডমিন: `https://আপনার-ডোমেইন/admin/` → প্রথমে ⚙️ সেটিংসে নিজের bKash/Nagad নাম্বার দিন।
6. লোকাল টেস্ট (টেলিগ্রাম ছাড়া): `DEV_MODE=1` দিয়ে চালিয়ে `http://localhost:3000/?dev=1001` খুলুন। **প্রোডাকশনে DEV_MODE=0 রাখুন।**

## কাজের ধারা
- **ডিপোজিট:** ইউজার আপনার নাম্বারে Send Money করে TrxID জমা দেয় → এডমিন প্যানেলে আপনার অ্যাপে মিলিয়ে ✔ অনুমোদন → ব্যালেন্স যোগ।
- **উত্তোলন:** ইউজারের ব্যালেন্স থেকে সঙ্গে সঙ্গে কাটে → আপনি নিজের bKash/Nagad থেকে "পাঠাতে হবে" অংকটি পাঠিয়ে ✔ চাপেন। বাতিল করলে ফেরত যায়।
- **লটারি:** পুরস্কার আপনি নিজে নির্ধারণ করেন (যেমন `1000,500,200`)। "ন্যূনতম টিকিট" পূরণ না হলে সময়ে অটো বাতিল ও সবাইকে রিফান্ড। প্যানেলে আয় বনাম পুরস্কার দেখে লোকসান এড়ান।

## নিরাপত্তা নোট
- টেলিগ্রামের `initData` সার্ভারে HMAC দিয়ে যাচাই হয়; ব্যালেন্স/টিকিট সব সার্ভারে, ডাটাবেস লেনদেন (atomic) দিয়ে।
- এডমিন লগইনে ভুল পাসওয়ার্ডে রেট-লিমিট আছে। শক্ত পাসওয়ার্ড দিন, `/admin/` এর URL গোপন না রেখে HTTPS ব্যবহার করুন।
- `data/lottery.db` নিয়মিত ব্যাকআপ নিন (এতে সব টাকার হিসাব)।
- ⚠️ **আইনি সতর্কতা:** বাংলাদেশে জুয়া/বেটিং সংক্রান্ত আইন কঠোর। লটারি চালানোর আগে প্রযোজ্য আইন ও লাইসেন্স সম্পর্কে নিজে নিশ্চিত হোন — এটি আইনি পরামর্শ নয়।

## পেমেন্ট মেথডের ছবি
এডমিন প্যানেল → ⚙️ সেটিংস → **পেমেন্ট মেথডের ছবি** → bKash/Nagad/Rocket এর নিচে "ছবি বদলান" চাপুন। ছবি অটো ২৫৬×২৫৬ হয়ে `data/uploads/` এ সেভ হয় এবং ইউজারের ডিপোজিট/উত্তোলন পেজে দেখায়। "মুছুন" চাপলে ডিফল্ট আইকন ফিরে আসে।

## ফাইল
`server.js` API+রাউটার • `lottery.js` টিকিট/ড্র/রিফান্ড • `db.js` SQLite • `bot.js` বট • `public/` ইউজার অ্যাপ • `public/admin/` এডমিন প্যানেল

## ☁️ Railway / Render এ ডিপ্লয়
- GitHub এ **ফাইলগুলো রুটে** আপলোড করুন (`server.js`, `package.json` সরাসরি রিপোর রুটে থাকবে; `public/` ফোল্ডার শুধু একবার — `public/public/` হবে না)।
- `requirements.txt` রাখবেন না (Python মনে করে pip চালায়) — এই জিপে সেটি নেই।
- Variables ট্যাবে `.env` এর মানগুলো বসান: `BOT_TOKEN`, `WEBAPP_URL` (Railway এর দেওয়া ডোমেইন), `BOT_USERNAME`, `ADMIN_PASSWORD`, `DEV_MODE=0`। `.env` ফাইল GitHub এ তুলবেন না।
- **Volume যোগ করুন** (Settings → Volumes → mount path `/data`) এবং Variables এ `DB_FILE=/data/lottery.db` দিন। না দিলে প্রতিবার ডিপ্লয়ে ইউজার/ব্যালেন্স ডাটা মুছে যাবে।
- Start Command: `npm start`। Node ভার্সন ২২ (`.node-version` দেওয়া আছে)।

## 📡 অটো ব্রডকাস্ট (চ্যানেল + বট)
ডিপোজিট সম্পন্ন, উত্তোলন সম্পন্ন, নতুন টিকিট ক্রয় ও লটারি ড্রের বিজয়ী — সব স্বয়ংক্রিয়ভাবে টেলিগ্রাম চ্যানেল ও বটের ইউজারদের কাছে যায়।
- এডমিন → ⚙️ সেটিংস → **Telegram Channel ID** দিন (`@channelname`, `t.me/channelname` বা `-100...`)।
- **বটকে চ্যানেলে অ্যাডমিন বানান** (মেসেজ পোস্টের অনুমতি সহ) — না হলে চ্যানেলে যাবে না।
- সেটিংসে `event_broadcast_channel`, `event_broadcast_bot` (1/0) দিয়ে চালু/বন্ধ, `broadcast_mask_names` (1 = নাম আড়াল, 0 = পুরো নাম)।
- এডমিন → 📢 ব্রডকাস্ট পেজে বট/চ্যানেলের স্ট্যাটাস ও শেষ ত্রুটি দেখা যায়।
